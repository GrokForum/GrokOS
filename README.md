# GrokOS

Source-built live DVDs. License: [GNU GPL v3.0](LICENSE).

Two images from one core: a private daily driver and a **public trim**. This repository is the public tree.

## Method

[Linux From Scratch](https://www.linuxfromscratch.org/) is the **method** (pin versions, compile from upstream sources, you build it). This repository does not vendor the LFS book.

Public first-boot agent: [cassian](https://github.com/farwaters/cassian) (empty vessel). Already-public companions: [it-project](https://github.com/farwaters/it-project), [stickynotes](https://github.com/farwaters/stickynotes).

House-only skills and private overlays do not ship here.

## Status

Pre-ISO. Lab exists off this tree. No live DVD yet.
