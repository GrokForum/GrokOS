# What GrokOS is

One LFS core. Two overlays from Stage 4.

| | Private | Public |
|--|---------|--------|
| First-boot agent | house direction + execution | cassian empty vessel only |
| Skills | house master tree | cassian empty vessel + token-optimiser + notice-board + already-public farwaters (`it-project`, `stickynotes`) + names in `ADD-BEFORE-MVP.md` |
| Release | later host tighten (named RFC) + workshop VDI | git clone, URL, or pin get `get-0.29.sh` (RFC-0.28/0.29). Offerings: **hardened** (first), **workstation**, **specialist** (later map). Deploy: **VM** (easy) or **tin** (preserve-environment). Media: OS curl, DVD, thumb later. Proved live seat: XFCE. GNOME and Hyprland stay compiled seats. The live disc does not start Hyprland. |
| Size | daily driver; not bound by DVD | workstation trim: docs/spreadsheets (DOCX/XLSX/PPTX), mail. Live ISO, if any, ≤ 4.7 GiB DVD-5. 2–4 GB RAM, 2 CPU. No hypervisor-in-guest |
| Personal trees | migrate skills; remount data | refuse vault and workshop trees |

Secrets ship as empty slots.

## Does not ship (public)

jax, videogen, movie-factory, trevor, keys, PROFILE, a private skill-tree dump, owner torrent/chat extras. The packer must fail if denylist paths land in the public tree.

Public **does** ship a daily workstation: Brave Origin, LibreOffice (Office Open XML interchange), Thunderbird. Customise by forking the overlay or picking a git profile.

cassian: [farwaters/cassian](https://github.com/farwaters/cassian). Companions: [it-project](https://github.com/farwaters/it-project), [stickynotes](https://github.com/farwaters/stickynotes).
